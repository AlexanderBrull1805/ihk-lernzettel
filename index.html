Welche Aussagen über useState sind korrekt?

  • ✓useState gibt einen aktuellen Wert und eine Setter-Funktion zurück
  • ✓Der Setter triggert typischerweise einen Re-Render
  • ✓Man sollte State immer direkt mutieren (z.B. state.count++)
  • ✓useState kann Initialwerte als Funktion erhalten (lazy init)
#85mehrere richtig

Welche Aussagen über das Dependency Array in useEffect sind korrekt?

  • ✓Es steuert, wann der Effekt erneut ausgeführt wird
  • ✓Ein leeres Array bedeutet: Effekt läuft nur einmal nach dem ersten Render (typisch)
  • ✓Ohne Array läuft der Effekt nach jedem Render
  • ✓Das Array speichert automatisch State-Werte dauerhaft

  • ✓useRef eignet sich u.a. für DOM-Zugriff (z.B. Input fokussieren)
  • ✓useRef ersetzt immer useState
  • ✓useRef-Werte werden bei jedem Render automatisch zurückgesetzt

  • ✓Sie zeigt oft eine NotFound/404-Komponente
  • ✓Sie matcht häufig erst, wenn keine andere Route passt
  • ✓Sie hat immer automatisch Vorrang vor allen anderen Routen
